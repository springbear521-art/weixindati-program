# 微信读书电脑答题助手

在电脑微信打开答题小程序后，程序截取整个小程序窗口，通过 DeepSeek 识题、搜索，并直接显示答案文字。每题限时 12 秒；程序不会代替你点击选项。

## 启动

需要 Windows、Python 3.10 或更新版本，以及 DeepSeek API 密钥。

1. 在文件资源管理器中打开含 `app.py` 的项目文件夹，点击地址栏，输入 `powershell` 并按回车。
2. 在打开的 PowerShell 中运行：

   ```powershell
   python app.py
   ```

   如果提示找不到 `python`，改用 `py app.py`。保持 PowerShell 窗口打开，答题结束后的汇总会显示在这里。
3. **首次使用**：在程序的“API 密钥”框粘贴 DeepSeek API Key，点击“保存密钥”。输入时字符会隐藏，保存后输入框清空，状态显示“已保存在 Windows 凭据管理器”。以后启动无需重输；要更换密钥，输入新密钥再点一次“保存密钥”。

密钥保存在当前 Windows 用户的凭据管理器中，不写进项目文件、Git 仓库或运行日志。已有的 `DEEPSEEK_API_KEY` 环境变量也可作为备用。调用 API 可能产生费用。

## 自动答题

1. 在电脑微信中打开小程序，停在“开始答题”之前。程序的“答题窗口”列表中选择小程序窗口；找不到时点“刷新窗口”。
2. 点击“开始自动监测”，再回小程序点击“开始答题”。监测界面保持与启动界面相同的窗口大小，底部有“立即识别当前题”和“停止并返回”按钮。把助手窗口放在小程序旁边，避免挡住题目。
3. 程序自动截取整个小程序窗口，无需框选。新题出现后会显示“搜索中…”，随后直接显示建议答案文字；请核对并在小程序中点选。如果第一题已经显示，点“立即识别当前题”。
4. 识别满 12 题后，最后一题答案保留约 12 秒，再自动停止并在 PowerShell 中打印题目答案。提前结束或漏题时，点“停止并返回”也会打印已有记录。

识图、搜索和判断约有 8.5 秒程序预算；网络慢时可能超时。看不清或证据不足时显示“无法判断”。

## 本次运行结果

一次 12 题的运行日志记录了 **16 次识图、12 次搜索、12 次答案判断**，共约 40 次 API 请求。完整答题流程平均用时 **2.77 秒**，最慢 **3.09 秒**；没有记录到超时、接口错误或同题重复搜索。

另有 4 次识图返回“无法判断”，没有继续搜索，可能是开始或结束画面触发。12 个建议答案中有 10 个指向第一项；日志没有实际判题结果，无法据此判断正确率。这些数字只代表这一次运行。

## 其他操作

- “截取窗口”可检查截图；“选图片”加“识别并搜索所选图片”可分析已有图片。非监测模式下可按 `F8` 快速答题。
- 本地日志在 `logs/quiz.log`，记录触发、耗时和错误类型，不记录密钥。查看最近 50 行：`Get-Content -LiteralPath '.\logs\quiz.log' -Tail 50`。本地日志和截图不会上传到 GitHub。
- 关闭助手窗口即可退出。主窗口会记住你调整后的大小和位置。
- 小程序窗口须保持可见；如果截到空白或别的内容，检查窗口是否被遮挡。截图会发送给 DeepSeek API，模型答案仍需核对。

测试命令：`python -m unittest discover -s tests -v`。
